# MVP representative corpus

This directory contains three short, original Chinese micro-novels released as
CC0-1.0 fixtures for executable-world evaluation. They were written for this
repository and contain no user or third-party prose.

The suite deliberately separates three failure surfaces:

- `glass-ledger`: false belief, deception, quotation attribution, and knowledge
  isolation;
- `ash-court`: a hidden physical/magical constraint, a public prohibition, a
  physically successful legal violation, and a due institutional process;
- `tide-alliance`: relationship and goal change, obligation, and simultaneous
  competition for one exclusive resource.

`gold.v2.json` is a selected, explicit semantic denominator. It does not claim
that every mention or event in the prose is annotated, and the repository does
not derive a quality threshold from these synthetic works. The manifest pins
source bytes and declares which evaluator layers must have a non-empty
denominator. Human review and any frozen model-specific baseline remain a
release decision, never an inventory-count shortcut.
